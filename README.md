# sql_library_manager

Local library Application that manages a collection of books. Uses HTML designs with an existing SQLite database. Dynamic application that uses JavaScript, Node.js, Express, Pug, SQLIte, and the SQL ORM Sequelize. 

## How to run the project

1. Install [Node.js](https://nodejs.org/) if you don't already have it.
2. Clone the repository and open the project folder in your terminal.
3. Run `npm install` to install the dependencies.
4. Run `npm start` to start the app.
5. Open `http://localhost:3000` in your browser.
